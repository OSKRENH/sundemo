# SunDemo — Aurix apartment card

Демонстрационная копия карточки квартиры №2 из проекта «Резиденция Омега» с дополнительным режимом **«Солнечный свет»**.

## Что реализовано

- компоновка экрана, шапка, просмотрщик и панель характеристик в стилистике исходной страницы Aurix;
- вкладки «С мебелью», «Без мебели» и «На этаже»;
- дополнительная вкладка «Солнечный свет»;
- псевдо-3D планировка с объёмными стенами;
- расчёт положения солнца по дате и времени для координат Москвы;
- динамические световые пятна и тени;
- быстрое переключение сезонов и автоматическое проигрывание дня;
- полноэкранный режим, избранное и кнопка «Поделиться»;
- адаптация под разные размеры экрана.

## Запуск

Проект статический. Откройте `index.html` через локальный HTTP-сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Ограничения демо

Это маркетинговая визуализация, а не официальный инженерный расчёт инсоляции. В текущей версии не учитываются соседние здания, балконы, глубокие откосы и выступы фасада.
