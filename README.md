# SunDemo · Резиденции Омега

Архивный просмотрщик Photoreal3d для квартиры №3 (секция 1, этаж 2, 65,7 м²) с интерфейсом AURIX. В нём доступны 3D, вид сверху и план, выбор сезона, шкала времени и проигрывание дня.

## Запуск

Страница работает на GitHub Pages и через любой локальный статический сервер. Из корня репозитория:

```sh
python -m http.server 8080
```

Откройте `http://localhost:8080/`. Каталог доступен по ссылке «Все планировки». В архиве была модель одной квартиры, поэтому остальные карточки и стрелки ведут на соответствующие страницы Photoreal3d.

`apartment-data.json` содержит геометрию и данные инсоляции из архивного просмотрщика. `catalog.json` содержит данные каталога и геометрию дома. Three.js 0.170.0 и лицензия MIT находятся в `vendor/`. `aurix.css` задаёт компоновку интерфейса поверх оригинальных стилей.

Экспорт FBX и редактор оформления доступны в сервисном меню. Журнал замечаний и загрузка правок открываются в исходном просмотрщике Photoreal3d, где работает сервис студии.
