# SunDemo — солнечный свет в квартире

Статическая демонстрация интерактивного блока для карточки квартиры ЖК «Резиденция Омега».

## Что работает

- фиксированная аксонометрическая камера;
- планировка из исходного SVG;
- расчёт положения солнца для Москвы по дате и времени;
- движение световых лучей и теней;
- быстрый выбор сезона и автоматическое воспроизведение дня;
- переключение между обычной планировкой и режимом солнечного света;
- адаптивный интерфейс без сторонних библиотек и сборки.

## Запуск

Откройте `index.html` через любой локальный HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого перейдите на `http://localhost:8080`.

## Ограничения демо

Это визуальная демонстрация, а не официальный расчёт инсоляции. В текущей версии не учитываются соседние здания, балконы, толщина фасада и точная 3D-геометрия оконных откосов.
